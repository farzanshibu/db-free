# DB Free — project instructions

Lightweight native database workbench. Rust core (Tauri v2) + React/TypeScript webview.
Follow `/architectural-guardrail`; this file is its translation to this codebase.

## Layers (request path)

```
UI component → src/lib/ipc.ts (client block) → #[tauri::command] (src-tauri/src/commands)
  → guard:: (THE BLOCK, src-tauri/src/guard/mod.rs) → services → store (rusqlite) | integrations (per-DB adapter) → database
```

| Layer | Owns | Never does |
|---|---|---|
| `src/lib/ipc.ts` | the only `invoke`; error normalisation; CommandMap ⇔ CommandName | UI |
| `commands/` | input validation (`ConnectionInput::validate`), call `guard::*`, call one service | touch store / integrations |
| `guard/` | timing, connection+session resolution, read-only lock, destructive confirm, timeout, bounds, history log | feature rules |
| `services/` | orchestrate store + integrations for one use case | import `tauri`, vendor crates |
| `integrations/` | one file per **adapter family** implementing `Integration` (45 families serving 69 engines: postgres family covers Supabase/Neon/Timescale/Cockroach/Yugabyte…, cassandra covers ScyllaDB, elasticsearch covers OpenSearch, sparql covers Jena/GraphDB/Stardog/Blazegraph/Virtuoso…); the only place that family's crate is imported. Shared helpers: `http.rs` (REST client + JSON→grid + client-side paging), `aws_sigv4.rs`, `gcp_auth.rs` | know about the UI |
| `store/` | the app's own SQLite (connections, history, buffers); only place `rusqlite` is used for app state | business rules |
| `adapters/` | `aes_gcm` (secret sealing) and `keyring` (master key) | anything else |

## Rules that are enforced (not just written)

- `pnpm check` = `scripts/guardrail.py` + `tsc` + `eslint` + `cargo clippy -D warnings` + `cargo test`. Hand back green.
- Every `.rs` / `.ts(x)` starts with a `SOT:` line. Grep with `grep -rl "SOT:.*<keyword>" src src-tauri/src` before creating anything.
- Every `#[tauri::command]` passes through `guard::local` / `guard::session` / `guard::statement`.
- TS types come from `src/lib/bindings` (generated by `pnpm bindings` from `#[ts(export)]`). Never hand-write a Rust shape in TS.
- No `any`, `as` casts, `@ts-ignore`; `unknown` only inside `src/lib/ipc.ts`. Clippy denies `unwrap`/`expect`/`panic` outside tests.
- UI is shadcn/ui (Radix primitives + cva, vendored as source in `src/components/ui`, `onClick`/`disabled`) on a black theme. `src/styles/globals.css` *is* the design system: it owns every colour utility, in both the shadcn vocabulary (`bg-primary`, `text-muted-foreground`, `border-input`, `ring-ring`) and this app's (`bg-background`, `bg-surface`, `text-foreground`, `text-muted`, `border-border`, `bg-accent`, `text-env-production`, syntax colours), aliased onto one palette. Never a palette class.
- Icons are Hugeicons only, through `Icon` / `IconName` in `src/lib/icons.tsx` — including inside `src/components/ui`. No lucide, no second icon set.
- Typed wrappers over the shadcn form primitives live in `src/components/global/Field.tsx` (`Field`, `AppSelect`, `Toggle`, `Check`, `Segmented`, `DateTimeField`, `NumberInput`); use them in features instead of assembling Label + control by hand. They stay generic over the caller's own string union, which is what keeps features free of casts.
- Every Radix overlay needs an explicit trigger (`DialogTrigger` / `PopoverTrigger` / `DropdownMenuTrigger` / `TooltipTrigger`), `asChild` when the trigger is the app's own `Button`. `TooltipProvider` is mounted once, in `App.tsx`.
- Secrets: never returned to the UI (`ConnectionSummary.hasSecret` only), sealed with AES-256-GCM, key in the OS keychain.

## Adding things

- **UI component:** reuse a primitive from `src/components/ui` first; add a new one with `npx shadcn@latest add <name>` (config in `components.json`), then make it fit this codebase — swap its lucide icons for `Icon`, replace any `bg-black`/palette class with a token, and keep it free of `any` and `as` (the repo bans both).
- **Engine:** `model::Engine` is the registry. Each variant maps to a `Family` (which adapter speaks to it), an `EngineKind` (picker category: relational, document, key_value, wide_column, graph, time_series, vector, search, multi_model, spatial, in_memory, analytical, new_sql, embedded, ledger, streaming, object, hierarchical, network, xml, graph_vector, rdf) and a `FormKind` (server / file / http_token / aws / gcp: which connection fields the UI shows). Wire-compatible products (Valkey, ScyllaDB, OpenSearch, Redpanda, Memgraph…) are new `Engine` variants on an existing family: no Rust adapter needed. Follow the numbered recipe at the top of `src-tauri/src/integrations/mod.rs`; compile errors list every place to touch. UI metadata (label, hint, field labels, URL schemes) lives in `src/lib/engines.ts` and fails `satisfies Record<Engine, …>` until every variant has an entry.
- **Non-SQL engines:** `execute` takes the engine's native language (Cypher, AQL, PromQL, SPARQL, Query DSL JSON, Redis commands…) and `fetch_page` maps the store onto tables (collections, indexes, labels, topics, graphs, keys). Client-side filter/sort/slice via `integrations::http::local::page` when the engine has no server-side paging. Adapters must refuse writes themselves when `read_only` is set, because the SQL guard cannot parse their language.
- **Object kind / tool:** `model::ObjectKind` and `model::Tool` are registries. Add the variant (+ `ALL`, `scoped()` if namespace-bound), run `pnpm bindings`, and `src/lib/objects.ts` fails `satisfies Record<ObjectKind, …>` until it has a label, icon and section. A family exposes kinds/tools by listing them in its adapter's `profile()`; that is the promise `objects()` / `object_detail()` / the tool method must keep. Object *actions* are native statements run through `execute_query`, so the guard applies to them.
- **Command:** add to `CommandName` (commands/mod.rs) → write the `#[tauri::command]` → register in `lib.rs` → export request type in the `export_bindings` test → `pnpm bindings` → add its signature to `CommandMap` in `src/lib/ipc.ts`.
- **Block concern:** insert a numbered step in `guard/mod.rs`; never a second guard.

## Run

```
pnpm install && pnpm tauri dev      # desktop app (needs Rust toolchain + libclang for RocksDB bindgen, cmake for aws-lc)
pnpm bindings                       # regenerate src/lib/bindings after Rust type changes
pnpm check                          # everything the CI runs
pnpm tauri build                    # .dmg / .msi / .AppImage+.deb for the host OS
```
